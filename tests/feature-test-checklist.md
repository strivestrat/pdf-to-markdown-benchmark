1. bold, italic, strikethrough, code and links
2. a bare web address made a link
3. curly quotes and dashes
4. heading levels
5. nested bullet lists
6. numbered lists
7. task-list check boxes
8. table column alignment
9. code colours
10. long code lines wrapped, not cut off
11. block quotes
12. footnotes
13. maths
14. definition lists
15. horizontal rules
16. accents, symbols and Japanese
17. raw HTML never run
18. a long table's header repeated on the next page
19. front matter hidden
20. page numbers
